Medium R04 · 445/TCP · This computer

File sharing (SMB)

Observed
TCP 445 is open; this port is used for Windows file and printer sharing (SMB).
What it means
File sharing is common on local networks. What matters is who can access the shared folders.
What to do
If you do not need sharing, consider turning it off. If you do, review share permissions, keep guest access disabled, and keep the system updated.
How to verify
Rescan with the same network and profile to compare the port state.
Info R06 · 80/TCP · Gateway

Web interface (HTTP/HTTPS)

Observed
TCP 80 is open; the device may offer a web service.
What it means
Routers, printers and smart devices often use a web interface for management. This alone is not a problem.
What to do
Make sure the admin interface does not use a default password and that the firmware is up to date.
How to verify
This informational item does not affect the score. You can check the version on the device's admin page.

07 / local-first

Your network. Your data. Your control.

  • The interface listens only on 127.0.0.1.Nothing is reachable from other computers
  • No account, no cloud, no telemetry.Scan results never leave your computer
  • Your data stays in %LOCALAPPDATA%\Lanora.Retention setting · delete one scan or all data

Scanning sends probes to the addresses you choose. The standard scan stays inside your directly connected private network, at most 256 addresses. Only scan networks you own or are authorized to test.
